# Visual concepts

This folder is for visual explainers, motion design, and storyboards.

## Potential visual elements

- fetal development timeline
- brain anatomy and hormone pathways
- conceptual diagrams of androgen receptor signaling
- timelines showing policy changes in Texas
- portraits and testimony from affected people
- simple animated explainers for public audiences

## Visual design principles

- clarity over novelty
- scientific accuracy over style alone
- use empathetic framing where lives are affected
- avoid simplification that erases nuance
