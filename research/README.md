# Repository overview

This folder is where the documentary's research foundation lives.

Use this space to organize:

- scientific papers and source summaries
- policy documents and legal timelines
- notes from interviews
- working citations and references
- claims that need verification

## Suggested subfolders

- `notes/` for research notes and source summaries
- `sources.md` for the working bibliography
- `questions.md` for open questions or missing data

## Research workflow

1. Identify a fact or claim you want to support.
2. Add a citation or source reference in `sources.md`.
3. Add a brief note in `notes/` summarizing what the source says.
4. Link that note back to the relevant script section or story beat.
