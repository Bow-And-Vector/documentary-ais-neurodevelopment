# Source tracker template

Use this as a working source log for the movie’s research and script.

## Field definitions

- Topic
- Source title
- Author(s) or organization
- Source type (journal article, review, policy doc, court filing, interview, report)
- Year
- Link or DOI
- Summary of key takeaway
- Relevance to documentary arc
- Confidence level (high / medium / low)
- Status (unverified / reviewed / cited in script / used in final edit)
- Notes / follow-up questions

## Source review rubric

Each source should be evaluated on three criteria:

1. Scientific validity
2. Relevance to the film’s argument
3. Clarity for a general audience

## Use in script workflow

For each scene, record:

- which source supports the claim
- whether the claim is direct evidence or contextual framing
- whether the source is strong enough to hold in the final film
